# Icons

Brand source: `logo.png` (1024×1024).

Chrome / store sizes are resized from that file:

| File | Size |
| --- | --- |
| `icon-16.png` | 16×16 |
| `icon-48.png` | 48×48 |
| `icon-128.png` | 128×128 |

Keep filenames in sync with `manifest.config.ts` and `ICON_PATHS` in `src/constants/icons.ts`.
